# C2-9 — حالت بلیتز جنگ: مدت ۱ ساعت

تاریخ: ۲۰۲۶-۱۰-۱۹ — شاخه: `arena/11b32a94-sib`

## خلاصه

جدال سیبی از یک رویداد ۵ ساعته به یک رویداد سریع و پرتنش **۱ ساعته** تبدیل شد و سپر صلح مدافع از ۵ ساعت به **۲ ساعت** کاهش یافت. هیچ قانون دیگری (هزینهٔ انرژی، فاصلهٔ ۳۰ ثانیه، سقف ۱۰ حمله، فرمول غنیمت ۱۵٪ با سقف حفظ سطح، سپر فقط برای مدافع) تغییر نکرد.

| قاعده | قبل | بعد |
|---|---|---|
| مدت جنگ | ۵ ساعت | **۱ ساعت** |
| سپر صلح مدافع | ۵ ساعت | **۲ ساعت** |
| هزینهٔ هر ضربه | ۲۰ انرژی | بدون تغییر |
| فاصلهٔ ضربات | ۳۰ ثانیه | بدون تغییر |
| سقف حمله | ۱۰ در هر جنگ | بدون تغییر |

## کد

### `services/war_service.py`

- `WAR_DURATION = timedelta(hours=1)` (قبلاً `hours=5`). مقدار پایان جنگ همان‌جا در `declare_war` ساخته می‌شود: `ends_at=now + WAR_DURATION` (خط ۲۶۴)؛ هیچ جای دیگری مدت جنگ hardcode نشده بود.
- `PEACE_SHIELD_DURATION = timedelta(hours=2)` (قبلاً `hours=5`)؛ در `finish_war` فقط برای مدافع: `castle.shield_until = now + PEACE_SHIELD_DURATION` (خط ۳۶۲).
- متن docstringهای `declare_war` و `finish_war` با ارجاع به همان ثابت‌ها به‌روزرسانی شد.

### `handlers/castle.py`

متن‌های کاربری مدت زمان را به‌صورت hardcode («۵ ساعت») داشتند و با تغییر ثابت‌ها قدیمی می‌ماندند؛ حالا از خود ثابت‌ها ساخته می‌شوند:

- `_duration_words(WAR_DURATION)` → «یک ساعت» و «یک‌ساعته» (برای ۱ ساعت؛ در غیر این صورت «{عدد} ساعت» / «{عدد} ساعته» با ارقام فارسی).
- `SHIELD_HOURS_TEXT` از `PEACE_SHIELD_DURATION` → «۲».
- صفحهٔ تأیید: «⚠️ تایید اعلان جنگ یک‌ساعته»، «⏳ مدت زمان نبرد: یک ساعت تمام»، «🛡 قانون صلح: ... ۲ ساعت سپر صلح می‌گیرد ...».
- پس از تأیید: «🚀 نبرد یک‌ساعته آغاز شد!» و «⏳ مهلت نبرد: یک ساعت تمام».

### `services/war_presentation.py`

پیام نتیجه از قبل ساعت سپر را از `PEACE_SHIELD_DURATION` می‌ساخت، پس خودکار «۲ ساعت سپر صلح فعال شد.» می‌گوید؛ فقط docstring به‌روزرسانی شد.

## تست‌ها

- `test_war_duration_is_1_hour` (نام قبلی: `test_war_duration_is_5_hours`) — `WAR_DURATION == timedelta(hours=1)`، `ends_at == now + ۱ ساعت` و `ends_at - started_at == ۱ ساعت`.
- `test_war_announcements_state_the_blitz_durations` — متن‌های اعلان جنگ/سپر از ثابت‌ها ساخته می‌شوند («یک ساعت»، «یک‌ساعته»، «۲»).
- به‌روزرسانی همهٔ تست‌های ۵ ساعته:
  - `test_war_peace_shield_is_2_hours_on_the_defender` — پایان ۱ ساعت، سپر ۲ ساعت؛ در `end + ۱ ساعت` هنوز در فهرست هدف نیست و در `end + ۲ ساعت` آزاد است.
  - `test_war_tie_has_no_loser_but_the_defender_is_shielded` — سپر `end + ۲ ساعت`.
  - `test_war_attacks_stop_at_one_hour_deadline` — ضربه در دقیقهٔ ۶۰ رد می‌شود.
  - `test_defender_gets_2h_shield_on_win_or_loss` / `test_defender_gets_2h_shield_after_a_draw` / `test_shielded_group_not_in_target_list` — `PEACE_SHIELD_DURATION == ۲ ساعت` و پنجرهٔ سپر بر همان مبنا.
  - `SHIELD_LINE = "۲ ساعت سپر صلح فعال شد."` برای تست‌های متن پیام پایان.
  - `END = START + WAR_DURATION` برای مجموعهٔ غنیمت/سپر، و پنجرهٔ سپر در تست نگه‌داری با `PEACE_SHIELD_DURATION`.
  - تست‌های UI (هشدار سپر و شروع جنگ) هم از ثابت‌ها استفاده می‌کنند؛ بررسی متن تأیید/اعلان هم‌زمان با همان تست‌ها اجرا می‌شود.

نتیجه:

- `tests/test_war.py`: **۹۴ موفق**، ۱ شکست از قبل موجود (`test_war_callback_edits_message_in_place`؛ روی HEAD تمیز هم شکست می‌خورد).
- مجموعهٔ کامل: **۱۵۱۶ موفق، ۲۵ شکست، ۱۳۸۳ خطای محیطی** (`sib_TEST_DATABASE_URL` تنظیم نشده). فهرست شکست‌ها با C2-8.5 **مو‌به‌مو یکسان** است؛ هیچ شکست تازه‌ای اضافه نشد.

## نکتهٔ استقرار

جنگ‌هایی که پیش از این تغییر شروع شده‌اند، `ends_at` ذخیره‌شدهٔ خودشان را دارند و طبق همان ۵ ساعت (یا هر مقدار قبلی) تمام می‌شوند؛ برای کوتاه‌کردن آن‌ها دستور داده نشده و migration‌ای هم نوشته نشد. جنگ‌های تازه از این پس ۱ ساعته‌اند. هیچ migration لازم نیست: `WAR_DURATION` و `PEACE_SHIELD_DURATION` فقط در کد تعریف شده‌اند و ستون/جدول تازه‌ای اضافه نشده است.
